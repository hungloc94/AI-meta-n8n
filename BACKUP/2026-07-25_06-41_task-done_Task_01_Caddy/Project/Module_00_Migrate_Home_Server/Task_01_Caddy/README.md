# Task 01: Phase 9 — Cài Caddy

## Mục tiêu
Cài Caddy làm reverse proxy trên Home Server Ubuntu.
Caddy tự động cấp HTTPS và điều hướng traffic vào các app.

## Phạm vi
- Cài Caddy trên Ubuntu 24.04 LTS
- Cấu hình Caddyfile cơ bản
- Verify Caddy chạy đúng

## Ngoài phạm vi
- Cấu hình domain public (làm ở Task 02 Cloudflare Tunnel)
- Cấu hình n8n (làm ở Task 03)

## Kết quả mong đợi
Caddy chạy và có thể reverse proxy đến localhost app.
