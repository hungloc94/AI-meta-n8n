# Outputs

Produce a verification report with:

- Overall PASS or FAIL.
- Evidence for each verified area.
- Remaining risks.
- Recommended improvements.
- Explicit statement that no unapproved changes were made.

## Required Result Format

```text
Overall Result: PASS|FAIL
Failed Area: <name or none>
Reason: <evidence-backed reason>
Remaining Risks:
- <risk or none>
Recommended Improvements:
- <improvement or none>
```
