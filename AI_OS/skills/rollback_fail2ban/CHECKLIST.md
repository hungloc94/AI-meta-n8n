# Checklist

- [ ] Confirm rollback is explicitly authorized.
- [ ] Identify active configuration path.
- [ ] Identify backup configuration path.
- [ ] Verify both files exist.
- [ ] Show diff before restore.
- [ ] Restore only the approved file.
- [ ] Validate Fail2ban configuration.
- [ ] Restart only Fail2ban if validation passes.
- [ ] Verify Fail2ban service status.
- [ ] Verify jail status.
- [ ] Verify SSH over required paths.
- [ ] Verify firewall posture.
- [ ] Document result and remaining risk.
