# Checklist

- [ ] Confirm sshd service status.
- [ ] Confirm sshd configuration syntax if permitted.
- [ ] Confirm port 22 listener.
- [ ] Confirm listener bind addresses.
- [ ] Review recent SSH logs.
- [ ] Review TCP states.
- [ ] Compare LAN and Tailscale behavior.
- [ ] Identify whether connection attempts reach sshd logs.
- [ ] Document whether sshd is healthy or suspect.
