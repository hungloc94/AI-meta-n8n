# Checklist

- [ ] Confirm Fail2ban service state.
- [ ] List enabled jails.
- [ ] Inspect the target jail status.
- [ ] Record banned IPs.
- [ ] Record `ignoreip` values.
- [ ] Inspect nftables rules.
- [ ] Inspect iptables rules.
- [ ] Check Fail2ban logs for relevant bans or unbans.
- [ ] Identify whether a trusted IP is banned.
- [ ] State confidence and evidence gaps.
