# Operations Templates

Shared templates for reusable AI_OS operational skills.

- `SAFETY_GUARDRAILS.md`: investigation, recovery, permanent-fix, and verification safety rules.
- `COMMAND_EVIDENCE.md`: standard format for command evidence.
- `NETWORK_VERIFICATION_MATRIX.md`: PASS/FAIL matrix for SSH, firewall, and Tailscale checks.
- `INCIDENT_REPORT_SECTIONS.md`: reusable incident-report section model.
- `ROLLBACK_PROCEDURE.md`: rollback documentation structure.

Skills should reference these templates instead of copying common rules.
