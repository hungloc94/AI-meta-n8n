# Command Evidence Template

Use this format when recording command evidence.

```text
## Command
<exact command>

## Time
<local timestamp and timezone>

## Purpose
<what fact this command proves or disproves>

## Output
<verbatim or materially complete output>

## Interpretation
<observed fact only; label inference if any>
```

## Evidence Rules

- Keep raw outputs when they are short.
- Summarize long outputs only after preserving the decisive lines.
- Redact secrets, tokens, keys, and unrelated personal data.
- Do not redact IP addresses that are required to prove network path or ban state.
- Include command failures because failures are evidence.
