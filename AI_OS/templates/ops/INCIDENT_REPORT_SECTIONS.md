# Incident Report Sections

Use these sections for incident reports produced by operational skills.

1. Executive Summary
2. Timeline
3. Evidence Collected
4. Root Cause
5. Recovery Actions
6. Permanent Fix
7. Verification Results
8. Final System Status
9. Remaining Risks
10. Recommended Improvements

## Root Cause Standard

A root cause statement must include:

- Failing behavior.
- Specific component responsible.
- Exact condition that triggered the failure.
- Evidence proving the condition.
- Why other plausible causes were ruled out.
- Confidence score.
